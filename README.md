# LÚKA

Prezentačný e-shop pre kvetinárstvo LÚKA s katalógom kytíc a animovaným príbehom na úvodnej stránke.

Živá stránka: [kvetinyluka.kozovy.com](https://kvetinyluka.kozovy.com)

## Technológie

- Next.js
- React
- TypeScript
- Motion

## Lokálny vývoj

```bash
npm install
npm run dev
```

Kontroly a produkčný build:

```bash
npm run lint
npm run typecheck
npm run build
```

Projekt sa exportuje ako statická stránka a nasadzuje cez Cloudflare Pages.
