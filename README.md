# LÚKA Bratislava — Premium Flower Shop Demo

🌸 **Live demo:** [kvetinyluka.netlify.app](https://kvetinyluka.netlify.app/)

A premium, responsive flower-shop e-commerce experience designed for same-day flower delivery in Bratislava.

> **Portfolio demo:** Orders are not processed and no real payments or customer data are collected.

## Highlights

- Premium editorial-style visual design
- Smooth scrolling and interactive animations
- Responsive experience across desktop, tablet, and mobile
- Flower catalogue with category browsing
- Shopping cart and checkout user flow
- Same-day delivery slot selection concept
- Slovak-language interface tailored to a Bratislava florist

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## About the Project

LÚKA is a concept website for a modern Bratislava flower studio. The project focuses on combining a refined brand experience with a realistic e-commerce flow—from browsing bouquets to selecting delivery and reaching checkout.

## Important Note

This is a frontend portfolio project. The checkout is a demonstration only; payments and orders are not processed.
